# Vault Connections

1. Confirm the vault root contains `01-CAPTURES` and `02-CONNECTIONS`.
2. Read all notes added to every `01-CAPTURES` subfolder during the last 7 days.
3. Search across all subfolders for 3 to 5 strong connections. Accept only these types:
   - **A:** The same underlying principle in two domains.
   - **B:** A contradiction that creates useful tension.
   - **C:** A pattern linking three or more notes into an unnamed insight.
   - **D:** A question in one note that another accidentally answers.
4. For each connection, name its type, write a one-sentence bridge, cite the source notes, and propose a content hook.
5. Create a note in `02-CONNECTIONS` for each accepted connection, linking the sources.

Reject obvious links. Do not force a connection merely to reach the maximum.
