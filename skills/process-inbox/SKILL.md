# Process Vault Inbox

1. Confirm the vault root, then read every note in `00-INBOX` and check recent `1on1s` records for Granola-synced meetings that have not yet produced appropriate durable context or follow-up captures. Preserve raw transcripts in place.
2. For a published tweet, preserve its full text exactly, save it under `04-PUBLISHED/tweets/YYYY-MM-DD-<slug>.md` with three tags and `type: tweet`, then remove it from the inbox.
3. For every other note, select the correct `01-CAPTURES` subfolder: `observations`, `reactions`, `patterns`, `questions`, or `numbers`. Sharpen it to one specific sentence, assign exactly three tags, and move it.
4. Review `1on1s` for notes lacking suitable files in `05-CLAUDE/context/`. Create or update context files with source frontmatter, topic headings, concrete details, quotes, uncertainty, and speaker attribution. Use existing calendar-derived context only to improve planning or relationship continuity; do not archive raw calendar events.
5. Report total notes processed, destinations, new context files, patterns noticed, and one connection worth exploring.

Never make a capture vague. Preserve multiple speakers' views separately.
